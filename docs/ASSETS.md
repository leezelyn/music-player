# 素材来源与差异

原 RPK 中的歌曲试听、Logo、系统功能图标和唱片图片都没有复制到最终审查稿。
本次未找到足够的逐项再分发授权记录，不能将它们一并改标为非商业许可。
原项目文件保持原样。

本目录所有 PNG 由 `scripts/generate-assets.py` 用 Python 标准库按几何形状绘制，
没有读取原图片、系统资源或外部字体，也没有下载图标库。
文件路径与原界面一致，便于维持模板结构；功能图标为 96×96，Logo 为 96×96，唱片为 384×384。
它们是这份公开副本的替代素材，视觉效果由用户审查，不能视为原版界面的等同验收。
生成结果的路径、尺寸和 SHA-256 记录在 `generated-assets.json`，

## 内置试听

三款 `src/common/sample.json` 的 `variants` 均为空，没有附带 `sample.bin`。
播放器沿用已有的空歌单状态和手机导入流程，歌曲、歌词、封面与手机传输能力仍保留。
界面中的原歌曲默认名称改为通用名称。
